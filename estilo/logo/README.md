# Logo — LHS Quant Lab

Escolhida em 19/10/2026: **touro geométrico** em âmbar sobre o fundo Terminal Âmbar.
Tudo aqui é gerado por `python scripts/gerar_logo.py` (Edge headless). Para mudar algo, altere o script e rode de novo.

| Pasta | Arquivo | Uso |
|---|---|---|
| `wallpaper/` | `lhs-wallpaper-1920x1080.png`, `-2560x1440`, `-3840x2160` | Papel de parede do PC (Full HD, 2K, 4K) |
| `instagram/` | `lhs-perfil-1080.png` (+ `.svg`) | Foto de perfil |
| `instagram/` | `lhs-story-1080x1920.png` | Fundo de story / destaque |
| `youtube/` | `lhs-perfil-1080.png` | Foto do canal |
| `youtube/` | `lhs-banner-2560x1440.png` (+ `.svg`) | Banner do canal (texto dentro da área segura 1546×423) |
| `site/` | `logo-horizontal.png` / `.svg` | Cabeçalho do site (fundo transparente, para fundo escuro) |
| `site/` | `logo-marca-512.png` / `.svg` | Só o touro, fundo transparente |
| `site/` | `favicon.svg`, `favicon-32.png`, `apple-touch-icon-180.png`, `icon-512.png` | Ícones do navegador e do celular |
| `site/` | `og-image-1200x630.png` | Imagem de compartilhamento (WhatsApp, LinkedIn, X) |

Os `.svg` com texto carregam as fontes do Google Fonts; usados em `<img>` o navegador não baixa a fonte, então no site prefira o PNG ou o SVG embutido no HTML.
